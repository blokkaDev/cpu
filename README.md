# 4-bit Simple CPU

I'm building this project for fun as my first cpu.
For this system I'm using C to simulate the cpu before actually projecting and building it.

You can use this as a guide for your own project!
Please send us a pull request or create a new issue to help the CPU grow faster. If this goes well I'm gonna build an 8-bit more complete cpu.

You can find my personal logisim tests in the "logisim_tests" folder or the img documentation in the "imgs" folder.

Oh, and just to be clear, I don't have much experience with C and am trying to learn it better. Any advice is welcome!!
